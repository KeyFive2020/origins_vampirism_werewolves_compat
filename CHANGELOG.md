# Changelog

## 1.1.4-mc1.20.1

- Added optional Pehkui 3.8 compatibility.
- Restores the player's Pehkui base scale to Minecraft's default when changing from another origin to Vampire, Werewolf, Vampire Hunter, or Human.
- Keeps the mod functional when Pehkui is not installed.
- Updated Vampirism development dependency to 1.10.16.
- Updated Strictly Origins development dependency to 4.0.0.
- Human protection now removes Sanguinare without applying temporary garlic or wolfsbane effects.
